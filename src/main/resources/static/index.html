Producer / Consumer demo

Open users in separate tabs. Fanout: A → B/B1/B2 (all get every message). Event log: C → D/D1/D2 (each group pulls its own copy). Work queue: F → E1 or E2 (exactly one worker per task).

Fanout · Producer

User A — type words

Broadcast to broadcast-topic.

 Fanout · Push

User B — live inbox

Auto-receive (same SSE hub as B1/B2).

 Fanout · Push

User B1 — live inbox

Same stream as B — also gets every broadcast.

 Fanout · Push

User B2 — live inbox

Same stream as B — also gets every broadcast.

 Event log · Producer

User C — type numbers

Append to order-events-topic.

 Event log · Pull · group d

User D — pull inbox

Own Kafka group — sees every number.

 Event log · Pull · group d1

User D1 — pull inbox

Different groupId — also sees every number.

 Event log · Pull · group d2

User D2 — pull inbox

Different groupId — also sees every number.

 Work queue · Producer

User F — submit task

Publish to task-queue-topic (competing workers).

 Work queue · Push · worker-1

User E1 — live (push)

Only tasks handled by worker-instance-1.

 Work queue · Pull · worker-2

User E2 — pull inbox

Only tasks handled by worker-instance-2.
